references/platform-ps1.md: TIMs from this game's tool have a wrong pixel-block length word (4x for 8 bpp, 2x for 4 bpp); compute the size from w*h*2 when parsing archive entries.

references/emulator-qa.md: games built on a coroutine thread library keep menu cursors as stack locals of the screen thread (fixed addresses per screen, e.g. 801FFAxx); the thread's saved return address (saved sp + 4) is a usable "this loop is live" test.
references/emulator-qa.md: blinking menu cursors make a press look ignored in a 1-in-2 shot sample; judge input by the cursor RAM value, not the shot.

references/emulator-qa.md: racing games may end a race only when the kart is on the finish-line surface (here a per-frame collision value) besides the lap count; poking laps alone finishes on some courses only. Check every race mode's own thread (boss, GP, VS here each had a different end condition).
references/emulator-qa.md (bash): `--var SCENE='x'` inside an unquoted $VAR expansion keeps no quotes, so SCENE becomes a nil global and the warp silently does nothing; always write "SCENE='x'" in double quotes.
references/emulator-qa.md: frame-end PC samples land in VSync on most frames; to find where a screen is stuck, dump code-looking words on the stack each frame (call chain) or count exec hits of the screen's main-loop and thread-resume addresses per frame.
references/graphics.md (survey): most PS1 text sprites here are fully opaque strips, so an alpha bbox is the whole sprite and only multi-line panels need line rects; on boxed plates the frame and the lettering share colours, so colour-based line splitting fails and the rects must be given by hand (gfx_script.py `jp@x,y,w,h`). Dedupe by blob hash first: 1,011 text TIMs were 453 blobs.
references/graphics.md (survey): cross-check sprite readings of names against any Shift-JIS copy on the disc (save titles here): two course names were misread from the sprites (ブッタ for ゴッタ, も一 for もー).
references/platform-ps1.md (FMV transcripts): a second faster-whisper pass that re-transcribes each row's clip alone (0.3 s padding) with an initial_prompt of the cast's names (tools/fmv_pass2.py) fixed most names (ムージョ, ドンジューロー, コケ/スカ, 三悪 for 山岳) and confirmed which lines were stock inventions (ご視聴ありがとうございました over music in 6 movies). The whole-movie prompt problem doesn't apply to short clips. ~13 s per row on CPU.

references/platform-ps1.md (FMV): a STR version 3 movie (here STAFF.STR) can be replaced frame by frame with version 2 frames: decode with ffmpeg (-f psxstr, -fps_mode passthrough gives exactly one PNG per frame), encode v2 from the picture (tools/mdec.py encode_rgb), same sectors per frame; the game's player took them. No v3 encoder needed.
references/emulator-qa.md (marker build): paint a TIM that holds one text row whole, not just its rect, and the marker shot shows how much of the sprite the game draws: that is the row's measured room (here 228 of 495 rows could grow). Neighbouring sprites can overlap a TIM's transparent margin, so look before growing.
references/graphics.md (lettering): menu art with a light inner and dark outer outline reads right only with two rings (darkest ink outside, lightest inside, commonest middle ink as solid fill); one outline with per-row sampled fill came out striped and pale. Try candidates on the real TIM beside the Japanese (tools/font_try.py), not in game first.
references/graphics.md (fonts): native grids measured: Tiny5 8 px (cap 5) for 8-10 px rows; Jersey 15 is 27 px native (15 px, desu-yo's credit size, is off-grid). Pillow takes float sizes, so Jersey 10 at 1400/75 works.
references/pipeline.md (repack): a real BPE re-encode of a 1-bit edit came out 2 bytes over the original's entry; taking the smallest of several block sizes (each within the largest block the disc's own streams use) fixed it. Measure the decoder limits from the disc (largest block out, stack depth) before raising the block size.
