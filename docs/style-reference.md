# Style reference

Taken from the sibling project (time-bokan-series-bokan-desu-yo-en, `docs/style-reference.md`), so the series sounds
the same in both games, plus this game's other trios. Subtitles are short and carry no speaker names, so each voice
must show in the line itself.

| Speaker | JP markers | English devices | Example |
|---|---|---|---|
| Dokurobey | 我が輩, だべ, べ, スカポンタン, おめえ | rustic and pompous; ", y'hear", "you numbskulls", "you lot" | 我が輩はドクロベエだべ → I am Dokurobey, y'hear! |
| Doronjo, Majo, Mujo, Atasha, Munmun, Yanyan | だよ, かい, おしまい | bossy, sharp; "Let's go!", "let 'em have it!" | 片っ端からやっておしまい! → ...let 'em have it, one and all! |
| Boyacky | ボクちゃん, ですよ, ポチッとな | fawning and smug; "little ol' me", "Annnd... click!" | ポチッとな → Annnd... click! |
| Tonzra, Walsa, Donjuro, Dowalski, Tonmentan | わい, まんねん, まんな, でっか (Kansai) | rough; ", I tell ya", "gonna", "ya" | 絶対勝つまんねん → We're gonna win for sure, I tell ya! |
| Grocky, Tobokke, Secovicci, Kosuinen, Dasainen | です, ございます | the polite planner; full sentences | 任せてくださいよマージョ様 → Leave it to us, Majo-sama! |
| Kyokanchin | であります | military; ", sir!" | 楽勝であります → This'll be a cinch, sir! |
| Mirenjo | わらわ, ぞよ, ございますの | royal; "we", "shall", formal | 皆のもの行くぞよ! → Everyone, forward! |
| Kokematsu, Sukadon | ゴー・トゥー・ザ・ビクトリー (English in the original) | keep their English as spoken | アイム・ソーリー → I'm sorry... |
| Omotchama | コロン | ends on "koron!" | 大変なことになったコロン → This is big trouble, koron! |
| Heroes (Gan-chan, Ai-chan, Zenderman-1, Yattodetaman, Ippatsuman, Itadakiman) | 俺, だ, ぞ | clean-cut, plain declaratives | 真の勇気を持つ者だけがなれるんだ → Only those with true courage can! |

Rules:
- Two lines at most, 288 px each, in Liberation Serif Bold 13 (`tests/test_mdec.py` is the gate).
- A row split across a pause reads across it with "..." at both ends.
- Catchphrases never change: "Arahora-sassa!", "Annnd... click!", "punishment time", "numbskulls".
- Puns get a new pun, never a note: 流石 three ways → "Genius, genie-us, gee, what a genius!"; 社長、会長、盲腸、小腸 →
  "President, chairman, colon, semicolon..."; 笑う門に苦よ来い → "laugh, and misery comes laughing back!".
- 主役の座 is "Top Billing" and 主役 "the star", so Dokurobey's promise reads "top billing in the new world".
- Graphics: Dokurobey's briefings carry his tic (", y'hear!"); menus are short imperatives ("Save Record", "Quit Game");
  messages are sentences with a full stop or "...".
