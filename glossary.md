# Glossary - Time Bokan Series: Bokan GoGoGo

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Seeded from the sibling project time-bokan-series-bokan-desu-yo-en (its D11: names checked on Tatsunoko's English site).

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated. Name order: Western (given name first).
- Romanisation source: official English names where they exist, else an earlier fan patch, else Hepburn without macrons.
- Credits: English.
- Register / flavour: slapstick parody of the Time Bokan anime; keep the villains' catchphrases punchy.
- Spelling: American.
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.
- Graphics text: all translated. The ボカン logo stays Japanese unless an official English logo turns up.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ -> ..., ！？ -> !?
- Dokurobey's tic だベエ: keep a verbal tic rather than dropping it (phase 6 picks the form).
